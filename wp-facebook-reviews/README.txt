== Description ==

**Display Facebook Page Reviews, Recommendations & X (Twitter) Posts on Your WordPress Site — Fast, Local & Official API Powered.**

**WP Review Slider** turns your **Facebook Page reviews**, **Facebook Recommendations**, and positive **X (formerly Twitter) posts** into high-converting on-site **testimonials** and **social proof**. Instead of slowing down your website with third-party embeds on every page load, this plugin downloads your reviews once, stores them in your WordPress database (`utf8mb4` emoji-ready), and serves them locally from your own server.

Best of all, WP Review Slider connects through the **official Facebook Graph API** and the **X API v2** — never risky scraping methods that violate platform terms.

### Why Choose WP Review Slider?

* **Official Facebook API & X API v2:** Connect your Facebook Page in a couple of clicks and search X (Twitter) posts using OAuth 1.0a (or Bearer Token fallback) for reliable, compliant imports.
* **Show Facebook Recommendations as 5-Star Reviews:** Facebook switched many business pages from 1–5 stars to Positive/Negative recommendations. WP Review Slider converts positive recommendations into **5-star ratings** so your review slider and badges look consistent and trustworthy.
* **Combine Facebook & X (Twitter) Testimonials:** Showcase Facebook reviews alone, X posts alone, or mix both together in a single responsive review slider, carousel, or grid.
* **Built-In Review Analytics Dashboard:** Visualize your average star rating, 1-to-5 star breakdown, review volume timeline, rating trends, and positive/negative keyword word clouds right inside WordPress.
* **Stored Locally for Peak Performance:** Zero external API calls on front-end page loads — built for fast Core Web Vitals, SEO, and page caching.

### How Facebook Reviews & Recommendations Work

1. Connect to our official Facebook app with a couple of clicks on the **Facebook** admin tab.
2. Click **Retrieve Reviews** to download your Facebook Page reviews and recommendations into your WordPress database.
3. Create a review template on the **Templates** tab, then insert the **WP Review Slider** block or paste the shortcode into any post, page, or widget area.

### How X (formerly Twitter) Posts & Testimonials Work

Search X for posts mentioning your brand, product, or event, save the best posts to your database, and display them with the X logo, linked `@handles`, and hashtags.

1. Enter your X Developer OAuth 1.0a credentials (Consumer Key, Consumer Key Secret, Access Token, Access Token Secret) or Bearer Token on the **X (Twitter)** tab.
2. Search posts using the **X API v2** (Recent Search covers the last 7 days; Full-Archive Search is supported if your X API tier includes it).
3. Click the download icon next to the posts you want to keep.
4. In your template **Filter** settings, set Review Type to **Facebook**, **X (Twitter)**, or **Both**, and optionally filter by source page.

**Note on X API Access:** X's Free developer tier does not include post search. A paid X API plan (such as Pay-Per-Use / Basic with Recent Search access) is required by X. Spaces in search queries act as `AND`; use `OR` (for example `BrandName OR City`) when matching either term.

== Installation ==

1. Upload the `wp-facebook-reviews` folder to the `/wp-content/plugins/` directory, or install **WP Review Slider** from **Plugins → Add New** in WordPress.
2. Activate the plugin through the **Plugins** menu in WordPress.
3. Open the **WP Reviews** menu in your WordPress admin.
4. Connect your Facebook Page on the **Facebook** tab and/or search posts on the **X (Twitter)** tab.
5. Check the **Review List** and **Analytics** tabs to manage and analyze your imported feedback.
6. Create a template on the **Templates** tab, then insert the **WP Review Slider** block or paste the shortcode into any page, post, or widget area.

== Frequently Asked Questions ==

= Are Facebook reviews and X posts stored on my server? =

Yes. After you download reviews from Facebook or posts from X, they are saved in your WordPress database on your own server. Your site serves those stored reviews locally instead of calling Facebook or X on every page view, which keeps pages fast and reliable.

= Does this plugin use the official Facebook API? =

Yes. WP Review Slider connects through the official Facebook Graph API. It does not use unauthorized scraping or crawling methods that can break or violate Facebook's terms.

= Can I show Facebook recommendations as 5-star ratings? =

Yes! Facebook replaced 1–5 star ratings with Positive and Negative recommendations on many pages. This plugin converts positive recommendations into a 5-star rating value so you can display them with stars in your review slider, grid, and summary badge.

= Can I display X (formerly Twitter) posts as testimonials? =

Yes. Add your X Developer OAuth 1.0a keys (Consumer Key, Consumer Key Secret, Access Token, Access Token Secret) or Bearer Token on the **X (Twitter)** tab, search for posts mentioning your business, and click download on the posts you want to showcase. In your template **Filter** settings, set Review Type to **X (Twitter)** or **Facebook & X (Twitter)**. Note: X requires a paid API plan with Recent Search access (last 7 days) or Full-Archive Search access.

= Why don't my X search results match what I expect? =

X search treats spaces as **AND** (all words must appear in the same post). Try a single keyword, an `OR` query (for example `BrandName OR City`), or an exact phrase in quotes. Recent search covers the last 7 days.

= Can I put Facebook reviews and X posts in the same review slider? =

Yes. In your template **Filter** settings, set Review Type to **Facebook & X (Twitter)** to mix both in one slider or grid, or filter by a single platform and source.

= Can I hide specific reviews or filter out low ratings? =

Yes. On the **Review List** page you can click the visibility icon to hide any individual review or post. In your template **Filter** settings, you can also filter by minimum rating, hide items without text, and choose newest or random sorting.

= How do I request a new feature? =

We are always looking for features to add! Post on the support forum or contact us on the [WP Review Slider website](https://wpreviewslider.com/contact/).
